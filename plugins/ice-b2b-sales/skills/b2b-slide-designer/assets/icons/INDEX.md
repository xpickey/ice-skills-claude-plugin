## วิธีใส่ icon ลงสไลด์ด้วย python-pptx

python-pptx รับเฉพาะภาพบิตแมป (PNG/JPG) จึงต้อง **แปลง SVG เป็น PNG ก่อน** และควรย้อมสีตอนแปลง

**ทางที่ 1 — builder ทำให้อัตโนมัติ (แนะนำ):** `~/.claude/agents/_lib/build_pptx.py` ในโหมดแม่แบบ (`ICE_TEMPLATE=...`) รับคีย์ `"icon": "mdi-finance"` ใน spec แล้วแปลง + ย้อมสี + วางลง placeholder ให้เอง (สีจาก `"icon_color"` ระดับ deck) โดยใช้ `qlmanage` ของ macOS แล้วทำพื้นให้โปร่งใสด้วย Pillow — ไม่ต้องติดตั้งอะไรเพิ่ม

**ทางที่ 2 — ทำเอง:**

```python
import subprocess, os
from pptx import Presentation
from pptx.util import Inches

svg = os.path.expanduser('~/.claude/skills/b2b-slide-designer/assets/icons/mdi-finance.svg')
tinted = '/tmp/mdi-finance-1E66A4.svg'
open(tinted, 'w').write(open(svg).read().replace('currentColor', '#1E66A4'))   # ย้อมสี
subprocess.run(['qlmanage', '-t', '-s', '512', '-o', '/tmp', tinted], check=True)  # → /tmp/mdi-finance-1E66A4.svg.png (พื้นขาว)
# ทำพื้นโปร่งใส: ดูฟังก์ชัน _icon_png ใน build_pptx.py (คำนวณ alpha จากช่องสีต่ำสุดของพิกเซล)
slide.shapes.add_picture('/tmp/mdi-finance-1E66A4.svg.png', Inches(0.6), Inches(0.6), Inches(0.75), Inches(0.75))
```

**เครื่องมือแปลง SVG → PNG ที่ตรวจในเครื่องนี้ (2026.09.05 ด้วย `which`):**

| เครื่องมือ | มีในเครื่อง | หมายเหตุ |
|---|---|---|
| `qlmanage` (macOS) | มี (`/usr/bin/qlmanage`) | ใช้ได้ทันที ผลลัพธ์พื้นขาว ต้องทำโปร่งใสต่อด้วย Pillow (มีแล้ว 11.3) |
| LibreOffice ตัวจริง | มี (`/Applications/LibreOffice.app/Contents/MacOS/soffice`) | `--headless --convert-to png` ได้ภาพขนาดเล็ก 24 px ไม่พอใช้บนสไลด์ · ห้ามเรียก `soffice` ใน PATH (เป็น shim) |
| `rsvg-convert` | ไม่มี | ติดตั้ง: `brew install librsvg` (ห้ามติดตั้งเองโดย agent — ต้องให้ user สั่ง) |
| `cairosvg` | ติดตั้ง Python package แล้วแต่ **ใช้ไม่ได้** เพราะไม่มี libcairo | แก้: `brew install cairo` แล้ว `pip install --force-reinstall cairosvg` (ให้ user สั่ง) |
| `magick` / `convert` / `inkscape` | ไม่มี | ไม่จำเป็น |
