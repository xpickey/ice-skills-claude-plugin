# การสร้างชุดสีใหม่เมื่อคลังสีเดิมไม่เข้ากับงาน — รายละเอียดของหัวข้อ 4.9

> **ไฟล์นี้ใช้ทำอะไร:** บอกขั้นตอนสร้างชุดสีขึ้นใหม่ด้วยตัวเองเมื่อชุดสีในคลัง (`catalog-gradients.md` และโฟลเดอร์ `gradients/`) ไม่ตรงกับโจทย์ แทนการไปหาชุดสีจากเว็บภายนอก
> **เงื่อนไขที่ต้องกลับไปดูก่อน:** เงื่อนไขว่างานใดเข้าข่ายสร้างชุดสีใหม่ อยู่ที่ `SKILL.md` หัวข้อ 4.9 · ชุดสีของ iCE ยังเป็นฐานตั้งต้นเสมอ และการเลือกฟอนต์ยังยึดหัวข้อ 4.6 กับ `references/font-selection.md`

## เงื่อนไขที่เข้าข่าย (เข้าข้อใดข้อหนึ่งก็พอ ถ้าไม่เข้าเลยให้ใช้ชุดสีจากคลังตามปกติ)

- user ขอชุดสีเฉพาะ หรือขอให้เป็นสีของแบรนด์ตนเอง
- user ระบุสีของแบรนด์มาให้ ไม่ว่าเป็นรหัสสีหรือชื่อสี
- user บอกอารมณ์ของงานตั้งแต่สามคำขึ้นไปที่คลังไม่มี เช่น สีมอสส์ สีไลเคน สีสมุนไพร
- user แนบภาพตัวอย่างอารมณ์งานหรือแถบสีมาให้

เมื่อเข้าเงื่อนไข ให้ถามหนึ่งครั้งว่า "จะสร้างชุดสีใหม่ตามอารมณ์งานที่สรุปไว้ หรือเลือกจากคลังซึ่งเร็วกว่าและมีตัวเลือกหลากหลาย" แล้วทำตามคำตอบ

## ลำดับการสร้างชุดสี (ทำต่อเนื่องจนจบ ไม่ถามเพิ่มระหว่างทาง)

1. **สีเน้น (accent)** — มาจากสีแบรนด์ของลูกค้า หรือกำหนดจากอารมณ์งาน: โทนอบอุ่นอยู่ช่วงองศาสี 30–60 · โทนเทคโนโลยี 220–250 · โทนพฤกษา 130–160 · โทนสีจัดจ้า 280–320 · โทนแสงแดด 60–80 · ความอิ่มตัวของสีให้อยู่ระดับกลาง ไม่จัดจนล้า
2. **สีพื้น (paper)** — ผสมสีเน้นลงไปเล็กน้อยให้พื้นมีอุณหภูมิสีเดียวกัน · ไม่ใช้ขาวบริสุทธิ์หรือดำบริสุทธิ์ · พื้นสว่างอยู่ที่ความสว่าง 95–98% · พื้นโทนกระดาษเก่า 92–95% · พื้นเข้ม 12–18%
3. **สีตัวอักษร (ink)** — ต้องต่างจากสีพื้นชัดเจน: พื้นสว่างใช้ตัวอักษรเข้มที่ความสว่าง 16–24% · พื้นเข้มใช้ตัวอักษรอ่อนที่ 88–96% · ผสมสีเน้นลงไปเล็กน้อยเช่นกัน
4. **ชุดสีเทา (greys)** — สร้าง 5 ถึง 9 ระดับระหว่างสีพื้นกับสีตัวอักษร · ทุกระดับผสมสีเน้นไปในทางเดียวกัน (สีเน้นอบอุ่นก็ใช้เทาอบอุ่น) เพื่อให้ลำดับชั้นของตัวอักษรดูเป็นชุดเดียวกัน
5. **สีตัวอักษรบนพื้นสีเน้น (accent-ink)** — สีเน้นสว่างใช้ตัวอักษรสีเข้ม สีเน้นเข้มใช้ตัวอักษรสีพื้น · ค่าความต่างของสีต้องผ่านเกณฑ์ WCAG อย่างน้อย 4.5 ต่อ 1
6. **การจับคู่ฟอนต์** — เลือกฟอนต์หัวเรื่องกับฟอนต์เนื้อความจากรายการที่อนุมัติใน `references/font-selection.md` · น้ำหนักของสองฟอนต์ต้องต่างกันอย่างน้อย 300 หน่วย · ต้องรองรับทั้งอักษรละตินและอักษรไทย

## การหมุนแนวทางกันชุดสีซ้ำกันสองรอบติด

บันทึกสามแกนของชุดสีที่สร้างไว้ ได้แก่ ระดับความสว่างของพื้น (เข้ม กลาง สว่าง) · ลักษณะฟอนต์หัวเรื่อง · ช่วงองศาสีของสีเน้น เมื่อสร้างชุดสีใหม่ในครั้งถัดไป ให้เปลี่ยนอย่างน้อยหนึ่งแกนจากครั้งก่อน
