## 2. วิธีจัดซื้อจัดจ้าง (เลือกตามวงเงิน/ลักษณะ)

| วิธี | ใช้เมื่อ |
|---|---|
| **e-bidding** | งานทั่วไป วงเงินสูง — แข่งราคาอิเล็กทรอนิกส์ |
| **e-market** | สินค้าทั่วไปมีในระบบ |
| **คัดเลือก** | เฉพาะเจาะจงคุณสมบัติ |
| **เฉพาะเจาะจง** | วงเงินต่ำ/เหตุพิเศษ |

**e-bidding:** ส่วนใหญ่ตัดสิน **ราคาต่ำสุดที่ผ่านเกณฑ์คุณสมบัติ** — ดังนั้นต้องผ่าน technical spec ก่อน แล้วแข่งราคา.

## 3. TOR — หัวใจของดีลภาครัฐ

- **TOR (Terms of Reference)** = ข้อกำหนดที่ผู้เสนอต้อง comply ทุกข้อ.
- **กลยุทธ์:** "ไม่ได้เขียน TOR ให้เขา แต่ให้ความรู้จนเขาเขียน TOR ที่เราตอบได้ดีสุด" (ช่วงก่อนออก TOR).
- **TOR response:** เทียบทีละข้อ COMPLY/PARTIAL/MISSING/DEVIATION — honest comply % (ดู `_capabilities/check.md` D9).
- **อย่ากุ comply** — สตง.ตรวจได้ + ผิดสัญญาภายหลัง.

## 4. IT Service Provider context

- TOR/contract ภาครัฐสำหรับ IT — เงื่อนไข SLA, warranty, source code, security.
- **Cloud Security Standard** + PDPA — ข้อกำหนด security/privacy ภาครัฐ.
- ผูก ERP/GFMIS → `domain/govt-gfmis.md`.
