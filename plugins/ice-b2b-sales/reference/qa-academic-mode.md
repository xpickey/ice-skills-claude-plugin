# โหมดตรวจงานวิชาการของผู้ตรวจคุณภาพ (อริส) — เมื่อผู้เรียกคือสมนึก

> **Version:** V01R01 | **Date:** 2026.09.05 | ย้ายออกมาจากไฟล์ agent `qa-master-agent.md` §6 (Pass 3 ของแผนแก้ทีม)
> **ไฟล์นี้ใช้ทำอะไร:** บอกอริสว่าเมื่อผู้เรียกคือสมนึก (agent `thesis-ai-det-col-agent` ฝั่งงานวิชาการ) ต้องเปลี่ยนวิธีตรวจอย่างไร ใครเป็นเจ้าของขั้นไหน และจะไม่ตรวจซ้ำกับสมนึกได้อย่างไร
> **ใครใช้:** อริส (agent `qa-master-agent`) ในขั้น E2 ของไฟล์ agent เมื่อซองคำสั่งมาจากสมนึก
> **เรื่องที่ไม่อยู่ในไฟล์นี้และอยู่ที่ใด:** ระเบียบวิธีตรวจทั้งฉบับ 7 ขั้น (Thai Document Audit Engine) อยู่ที่ `~/.claude/skills/thesis-ai-det-col/references/10_academic_audit_engine.md` ซึ่งเป็นบ้านเดียว — อริสถือ pointer และความเป็นเจ้าของรายขั้น ไม่คัดลอกเนื้อมา

## 1. ขั้นที่ 0 บังคับก่อนเริ่มทุกครั้ง — หาเกณฑ์มาตรฐานของเอกสารให้ได้ก่อน (Resolve Standard)

ลำดับการหา: ซองคำสั่งระบุเกณฑ์มา ใช้ทันที → ไม่มี ให้เปิด skill ประจำชนิดเอกสาร (เช่นดุษฎีนิพนธ์ มจร ใช้ `~/.claude/skills/phd-mcu-pa-dissertation`) → ไม่มี ให้สกัดจากไฟล์แม่แบบที่ user ให้ → ไม่มีทั้งหมด ให้หยุดถาม user ผ่านผู้เรียก — หลักสูงสุด: ตรวจตามมาตรฐานของเอกสารฉบับนั้น ไม่ใช่ตามเกณฑ์ที่จำมา · ผลของขั้นนี้คือ "Standard Card" ตามรูปแบบในหัวข้อ 1.2 ของ engine

## 2. การแบ่งเจ้าของขั้น

| ขั้น | เนื้อหา | เจ้าของ |
|---|---|---|
| 0 | หาเกณฑ์และบัญชีอ้างอิง | อริส |
| 1 | ไล่รายหัวข้อพร้อมยามเฝ้าการอ้างอิง — เทียบชุดปี พ.ศ. ในวงเล็บให้ตรงกันทุกชุด | อริส |
| 2 | สำนวน AI และคำซ้ำ | สมนึก (เจ้าของน้ำเสียงวิชาการ) — อริสไม่แตะ |
| 3 | รูปแบบตามวารสาร ตรวจบน PDF ที่ export จริง (สาย PDF วิชาการของ D7) | อริส |
| 4 | เทียบการอ้างอิงสองทิศทาง ในเนื้อกับท้ายเล่ม | อริส |
| 5 | จับคู่รายการอ้างอิงกับไฟล์ต้นทางจริง | อริส (สมนึกเป็นผู้ยึดหลัก) |
| 6 | ถ้อยคำเชิงวิชาการ | สมนึก — อริสไม่แตะ |
| 7 | ด่านสุดท้าย ตรวจซ้ำทั้งฉบับบนรุ่นสุดท้าย | อริส |

## 3. การกันงานซ้ำและระดับความลึก

ซองคำสั่งที่มีธง `d5_done_by_thesis` เป็นจริง แปลว่าสมนึกตรวจสำนวน AI แล้ว อริสข้ามมิติ D5 ได้ · ระดับ FAST ตรวจขั้น 1, 3, 4 · ระดับ FULL ตรวจครบขั้น 0 ถึง 7 พร้อมตรวจซ้ำฉบับสุดท้าย · เอกสารที่มีภาษาบาลี ใช้เครื่องตรวจบาลีใน `qa-detection-engines.md` หัวข้อ 6 ร่วมด้วย
