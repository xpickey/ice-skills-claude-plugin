## 1. สนธิ (Sandhi) — การต่ออักขระให้เนื่องกัน

**นิยาม (PALIdict):** "วิธีต่อศัพท์และอักขระให้เนื่องกันด้วยอักขระ" เพื่อย่ออักขระ ช่วยการแต่ง และให้เสียงไพเราะ · **3 ประเภท:** สระสนธิ (7 วิธี) · พยัญชนะสนธิ (5 วิธี) · นิคหิตสนธิ (4 วิธี) · **เหตุที่ต้องรู้:** คำในคัมภีร์มักอยู่ในรูปสนธิ — ถ้าแยกไม่ออกจะหาศัพท์เดิมในพจนานุกรมไม่เจอ (Codex context_repair #1)

### 1.1 สนธิกิริโยปกรณ์ 8 — "เครื่องมือ" ที่ใช้ทำสนธิ (PALIdict)
| # | วิธี | ความหมาย | ตัวอย่าง `[มาตรฐาน]` |
|---|---|---|---|
| 1 | **โลปะ** (lopa) | ลบ | ยสฺส + อินฺทฺริยานิ = ยสฺสินฺทฺริยานิ (ลบ อ หน้า) |
| 2 | **อาเทส** (ādesa) | แปลง | อิ → ย: ปฏิสนฺถารวุตฺติ+อสฺส = ปฏิสนฺถารวุตฺยสฺส · อุ → ว: พหุ+อาพาโธ = พหฺวาพาโธ |
| 3 | **อาคม** (āgama) | ลงตัวอักษรเพิ่ม | ย อาคม: น+อิมสฺส = นยิมสฺส · ม อาคม: ลหุ+เอสฺสติ = ลหุเมสฺสติ |
| 4 | **วิการ** (vikāra) | ทำให้ผิดจากเดิม (อิ→เอ, อุ→โอ) | มุนิ+อาลโย = มุเนลโย · สุ+อตฺถิ = โสตฺถิ (`[มาตรฐาน]` — แก้จาก "โสคติ" ที่ไม่ใช่คำจริง ตามที่เทพชี้) |
| 5 | **ปกติ** (pakati) | คงรูปเดิม | โก+อิมํ = โก อิมํ (ไม่สนธิ) |
| 6 | **ทีฆะ** (dīgha) | ทำสระสั้นให้ยาว | สทฺธา+อิธ = สทฺธีธ · กึสุ+อิธ = กึสูธ |
| 7 | **รัสสะ** (rassa) | ทำสระยาวให้สั้น | โภวาที+นาม = โภวาทินาม · ยถา+ภาวี = ยถภาวี |
| 8 | **สัญโญค** (saṃyoga) | ซ้อนพยัญชนะ | อิธ+ปโมทติ = อิธปฺปโมทติ · จาตุ+ทสี = จาตุทฺทสี |

### 1.2 สระสนธิ (Sarasandhi) — สระหน้า + สระหลัง `[มาตรฐาน — โครงตาม PALIdict 7 วิธี]`
| กฎ | เงื่อนไข | ตัวอย่าง (คำเดิม = รูปสนธิ) |
|---|---|---|
| **โลปะสระหน้า** | สระหน้าเป็นรัสสะ สระหลังต่างชนิด | ยสฺส+อินฺทฺริยานิ = ยสฺสินฺทฺริยานิ · โนหิ+เอตํ = โนเหตํ · สเมตุ+อายสฺมา = สเมตายสฺมา |
| **โลปะสระหลัง** | สระหลังเป็น อ/อิ หลัง เอ/โอ | เต+อสฺส = เตสฺส · โส+อหํ = โสหํ · จตฺตาโร+อิเม = จตฺตาโรเม |
| **ทีฆะ** หลังโลปะ | ลบสระหน้า แล้วสระหลังทีฆะ | ตตฺร+อยํ = ตตฺรายํ · สทฺธา+อิธ = สทฺธีธ · พุทฺธ+อนุสฺสติ = พุทฺธานุสฺสติ |
| **อาเทส อิ/อี → ย** | สระหน้าเป็น อิ/อี สระหลังไม่ใช่ อิ/อี | อคฺคิ+อาคาร = อคฺยาคาร · ปฏิ+อคฺคิ = ปจฺจคฺคิ (แปลง ติ เป็น จฺจ) |
| **อาเทส อุ/อู → ว** | สระหน้าเป็น อุ/อู สระหลังไม่ใช่ อุ/อู | พหุ+อาพาโธ = พหฺวาพาโธ · อนุ+เอติ = อนฺเวติ · จกฺขุ+อาปาถํ = จกฺขฺวาปาถํ |
| **อาเทส เอ → ย · โอ → ว** | เอ/โอ หน้า สระหลัง | เต+อสฺส = ตฺยสฺส · โส+อสฺส = สฺวสฺส · เม+อยํ = มฺยายํ · โย+อหํ = ยฺวาหํ |
| **อาคม** | ลง ย ว ม ท น ต ร ฬ | น+อิมสฺส = นยิมสฺส · ติ+องฺคิกํ = ติวงฺคิกํ · ลหุ+เอสฺสติ = ลหุเมสฺสติ · อตฺต+อตฺถํ = อตฺตทตฺถํ · อิโต+อายติ = อิโตนายติ · ยสฺมา+อิห = ยสฺมาติห · นิ+อนฺตรํ = นิรนฺตรํ · ฉ+อภิญฺญา = ฉฬภิญฺญา |
| **ปกติ** | ไม่ต่อ (สระหน้ายาว/นิบาต) | โก อิมํ · เอวํ อาห (คงไว้) |

### 1.3 พยัญชนะสนธิ (Byañjanasandhi) `[มาตรฐาน — PALIdict 5 วิธี]`
| กฎ | ตัวอย่าง |
|---|---|
| **โลปะ** นิคหิตหน้าพยัญชนะ / ลบพยัญชนะซ้อน | ตํ+สนฺตํ = ตสนฺตํ (ลบ ํ) · สาธุ+ทสฺสนํ = สาธุ ทสฺสนํ |
| **อาเทส** ตฺ ทฺ ธฺ → จฺ/ชฺ ฯลฯ ตามวรรค | ปฏิ+อคฺคิ = ปจฺจคฺคิ (ตฺย→จฺจ) · อธิ+อาคม = อชฺฌาคม (ธฺย→ชฺฌ) · อิติ+เอวํ = อิจฺเจวํ · อภิ+อุคฺคจฺฉติ = อพฺภุคฺคจฺฉติ (ภิ→พฺภ) |
| **อาคม** ลง ร ท ฯลฯ | สพฺภิ+เอว = สพฺภิเรว · ปาตุ+อโหสิ = ปาตุรโหสิ · นิ+อนฺตรํ = นิรนฺตรํ |
| **ทีฆะ/รัสสะ** สระหน้าพยัญชนะซ้อน | (ก่อนซ้อน) ปฏิ+กมฺม = ปฏิกฺกมฺม · อุ+ทฺธํ = อุทฺธํ |
| **สัญโญค** (ซ้อน) พยัญชนะหลังอุปสัค/นิบาต | อิธ+ปโมทติ = อิธปฺปโมทติ · ป+กมติ = ปกฺกมติ · ทุ+กรํ = ทุกฺกรํ · สุ+ปฏิปนฺโน = สุปฺปฏิปนฺโน |
**กฎซ้อนพยัญชนะ (สัญโญค):** ซ้อนได้เฉพาะ**ตัวที่ 1 3 5 ของวรรค** และ ย ล ส · ตัวที่ 2/4 (ธนิต) ซ้อนด้วยตัวที่ 1/3 ของวรรคเดียวกัน (ทุกฺข ไม่ใช่ ทุขฺข · สทฺธา ไม่ใช่ สธฺธา) — สอดคล้องกฎตัวสะกด-ตัวตามใน `07` §3

### 1.4 นิคหิตสนธิ (Niggahitasandhi) `[มาตรฐาน — PALIdict 4 วิธี]`
| กฎ | ตัวอย่าง |
|---|---|
| **อาเทส นิคหิต → นาสิกของวรรค** เมื่อตามด้วยพยัญชนะวรรค (ก วรรค→งฺ · จ→ญฺ · ฏ→ณฺ · ต→นฺ · ป→มฺ) | ตํ+การุณิกํ = ตงฺการุณิกํ · ธมฺมํ+จเร = ธมฺมญฺจเร · สํ+ฐิโต = สณฺฐิโต · ตํ+ธมฺมํ = ตนฺธมฺมํ · สํ+ปนฺโน = สมฺปนฺโน |
| **อาเทส นิคหิต → ม / ท** เมื่อตามด้วยสระ | ตํ+อหํ = ตมหํ · ยํ+อาหุ = ยมาหุ · เอตํ+อโวจ = เอตทโวจ (→ ท) · ยํ+อิทํ = ยทิทํ |
| **อาเทส นิคหิต → ญฺ** เมื่อตามด้วย เอ/ห/ย | ตํ+เอว = ตญฺเญว · ตํ+หิ = ตญฺหิ · สํ+โยโค = สญฺโญโค (ย→ญ) |
| **โลปะ นิคหิต** | ตํ+สนฺตํ = ตสนฺตํ · อริยสจฺจานํ+ทสฺสนํ = อริยสจฺจานทสฺสนํ |
| **อาคม นิคหิต** (ลงเพิ่ม) | จกฺขุ+อุทปาทิ = จกฺขุํ อุทปาทิ · อว+สิโร = อวํสิโร |
**ตัวอย่างสำคัญในคัมภีร์:** เอวมฺเม สุตํ = เอวํ+เม (นิคหิตหน้าสระ เอ อาเทสเป็น ม แล้วเขียนติดกันเป็น เอวมฺเม — กฎแถว "นิคหิต → ม/ท เมื่อตามด้วยสระ") · สมฺพุทฺธ = สํ+พุทฺธ (นิคหิตหน้า พ วรรค ป อาเทสเป็น มฺ — กฎแถวแรก) · ส่วน สมฺมา เป็นนิบาตคำเต็ม ไม่แยกสนธิในที่นี้

### 1.5 วิธีแยกสนธิเมื่อแปล (Workflow — คู่กับ `06` §9 B1)
① เห็นสระยาวผิดปกติกลางคำ / พยัญชนะซ้อนที่ไม่ใช่รากศัพท์ / นาสิกหน้าพยัญชนะวรรค → สงสัยสนธิ ② ลองตัดที่จุดนั้นเป็น 2 ศัพท์ แล้วคืนรูปด้วยกฎย้อนกลับ (ทีฆะ→รัสสะ · ย→อิ · ว→อุ · นาสิกวรรค→นิคหิต · ซ้อน→เดี่ยว) ③ ตรวจว่าทั้ง 2 ศัพท์มีในพจนานุกรม (`08` §4) และวิภัตติสอดคล้องประโยค ④ ตัดสินไม่ได้ = ใช้ DPD/DPR ที่แยกสนธิให้อัตโนมัติ

## 2. สมาส (Samāsa) — นามศัพท์ ≥2 ย่อเป็นบทเดียว

**นิยาม (PALIdict · ตำรา น.62 เรียก "บทสมาส" เป็นประธานได้):** "นามศัพท์ตั้งแต่ 2 ขึ้นไป ย่อเข้าเป็นบทเดียวกัน" โดยมักลบวิภัตติของบทหน้า · **2 ลักษณะ:** **ลุตตสมาส** (ลบวิภัตติบทหน้า — ราชปุริโส) · **อลุตตสมาส** (ไม่ลบ — ปภงฺกโร, ทูเรนิทานํ)
**วิคคหะ (วิเคราะห์)** = รูปประโยคที่แสดงศัพท์เดิมก่อนเข้าสมาส — ต้องเขียนได้เมื่ออ้างสมาสในงานวิชาการ

| 4 | **ทวันทะ** (Dvanda) | นามนาม ≥2 ศัพท์ **ฐานะเท่ากัน** ("และ") · สมาหาร (เอก.นปุง.) / อสมาหาร (พหุ.) | **สารีปุตฺตโมคฺคลฺลานา** = สารีปุตฺโต จ โมคฺคลฺลาโน จ · ปตฺตจีวรํ = ปตฺโต จ จีวรํ จ (สมาหาร — ตำรา น.62) `[มาตรฐาน]` | พระสารีบุตรและพระโมคคัลลานะ · บาตรและจีวร |

| 6 | **พหุพพิหิ** (Bahubbīhi) | สมาสคุณ — **มีบทอื่นเป็นประธาน** (ทั้งสมาสเป็นคุณนามขยายนามข้างนอก) · ใช้ ย ศัพท์ในวิคคหะ | **ชิตินฺทฺริโย** = ชิตานิ อินฺทฺริยานิ เยน โส (ผู้มีอินทรีย์อันชนะแล้ว) · ปหูตชิวฺโห = ปหูตา ชิวฺหา ยสฺส โส `[มาตรฐาน]` | (ผู้)มีอินทรีย์ชนะแล้ว · มีลิ้นใหญ่ |

**วิธีสังเกตประเภท (คู่มือปฏิบัติ):** มีเลขหน้า → ทิคุ · มีอุปสัค/นิบาตหน้า → อัพยยีภาวะ · "และ" → ทวันทะ · แปลว่า "ผู้มี…" ขยายคำอื่น → พหุพพิหิ · บทหน้าเป็น "ของ/ใน/ด้วย/แก่" → ตัปปุริส · บทหน้าเป็นคุณศัพท์ตรง ๆ → กัมมธารยะ

## 3. ตัทธิต (Taddhita) — ปัจจัยต่อท้ายนาม/อัพยยะ สร้างศัพท์ใหม่

**นิยาม (PALIdict):** "ปัจจัยประเภทหนึ่ง ใช้ลงท้ายนามศัพท์หรืออัพยยศัพท์ เพื่อแทนเนื้อความของศัพท์อื่น" · ตำรา น.62 ยก **สามเณโร** (ผู้เป็นเหล่ากอแห่งสมณะ) และ **สหายตา** (ประชุมแห่งสหาย) เป็นตัวอย่างบทตัทธิต

### 3.1 สามัญญตัทธิต — 13 ชนิด `[โครงจาก PALIdict · ปัจจัย/ตัวอย่างมาตรฐาน]`
| ชนิด | ปัจจัย | แปลว่า | ตัวอย่าง = วิคคหะ |
|---|---|---|---|
| **โคตตตัทธิต** (โคตฺต · gotta) | ณ ณายน ณาน เณยฺย ณิ ณิก ณว เณร | เหล่ากอ/โคตร | วาสิฏฺโฐ = วสิฏฺฐสฺส อปจฺจํ · **สามเณโร** = สมณสฺส อปจฺจํ (เณร) |
| **ตรัตยาทิตัทธิต** | ณิก | ข้าม/ทำ/เกี่ยว | นาวิโก = นาวาย ตรตีติ (ผู้ข้ามด้วยเรือ) · ธมฺมิโก |
| **ราคาทิตัทธิต** | ณ | ย้อม/เกี่ยวกับ | กาสาวํ = กสาเวน รตฺตํ (ผ้าย้อมน้ำฝาด) |
| **ชาตาทิตัทธิต** | อิม อิย กิย | เกิด/มีใน | ปุริโม = ปุเร ชาโต · โพธิปกฺขิโย |
| **สมุหตัทธิต** (สมูห · samūha) | กณฺ ณ ตา | หมู่/ประชุม | มนุสฺสตา = มนุสฺสานํ สมูโห · **สหายตา** = สหายานํ สมูโห (ตำรา น.62) |

### 3.2 ภาวตัทธิต (ความเป็น…) `[PALIdict]`
ปัจจัย **ตฺต ณฺย ตฺตน ตา ณ กณฺ** — แปลว่า "ความเป็น": ปุถุชฺชนตฺตํ = ปุถุชฺชนสฺส ภาโว (ความเป็นปุถุชน) · อาโรคฺยํ = อโรคสฺส ภาโว (ณฺย) · ปุถุชฺชนตา (ตา) · สามญฺญํ = สมณสฺส ภาโว (ณฺย — ความเป็นสมณะ)

### 3.3 อัพยยตัทธิต (ประการ/อย่าง) `[PALIdict]`
ปัจจัย **ถา ถํ** — ยถา (โดยประการใด) · ตถา (โดยประการนั้น) · สพฺพถา (โดยประการทั้งปวง) · กถํ (โดยประการไร = อย่างไร) · อิตฺถํ (โดยประการนี้)

## 4. เปรียบเทียบกลไกสร้างศัพท์ 3 ชั้น (สรุปเพื่อแยกบทตอนแปล)
| กลไก | ต่อกับ | ผลลัพธ์ | ตัวอย่าง |
|---|---|---|---|
| **กิตก์** (`04` §8) | **ธาตุ** | นาม/กิริยา | ทา+ณฺวุ = ทายก · ทา+ต = ทินฺน |
| **ตัทธิต** | **นาม/อัพยยะ** | นามใหม่ (มีความหมายเพิ่ม) | สมณ+เณร = สามเณร · ภค+วนฺตุ = ภควา |
| **สมาส** | **นาม + นาม** | บทเดียว | ราช+ปุริส = ราชปุริโส |
| **สนธิ** (`§1`) | **อักขระ + อักขระ** | เชื่อมเสียง (ไม่สร้างความหมายใหม่) | เอวํ+เม = เอวมฺเม |
**ลำดับวิเคราะห์คำยาว:** แยกสนธิ → แยกสมาสเป็นบท → ในแต่ละบท ดูว่ามีตัทธิต/กิตก์ไหม → หาธาตุ/ศัพท์เดิม → เปิดพจนานุกรม
