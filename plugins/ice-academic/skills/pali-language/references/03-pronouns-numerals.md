> **Version:** V01R04 · 2026.09.04 · ส่วนหนึ่งของ skill `pali-language` · R04 (เทพ delta): ย้ายหมายเหตุ H5 ไปใต้ตาราง อมฺห §4 · R03 (เทพ H5/M16): ตุมฺหํ/อมฺหํ พหุ. `[มาตรฐาน]` · อมุ นปุง · R02 (QA อริส): ถอนข้ออ้างสังขยา 60-90 + เติม ลกฺขํ · เติม เต/โว ในตุมฺห ต. · ป้าย `[มาตรฐาน]` ที่ อมฺเห/ยายํ · รูปสำรองปูรณสังขยา 11-20

## 2. ต ศัพท์ (เขา / นั้น) — 3 ลิงค์ (ตำรา น.34-35)

### 2.1 ปุงลิงค์
| วิภัตติ | เอกวจนะ | พหุวจนะ |
|---|---|---|
| ป. | โส so | เต te |
| ทุ. | ตํ, นํ taṃ, naṃ | เต, เน te, ne |
| ต. | เตน tena | เตหิ tehi |
| จ. | ตสฺส, อสฺส tassa, assa | เตสํ, เตสานํ, เนสํ, เนสานํ tesaṃ, tesānaṃ, nesaṃ, nesānaṃ |
| ปญ. | ตสฺมา, อสฺมา, ตมฺหา tasmā, asmā, tamhā | เตหิ tehi |
| ฉ. | ตสฺส, อสฺส | เตสํ, เตสานํ, เนสํ, เนสานํ |
| ส. | ตสฺมึ, อสฺมึ, ตมฺหิ tasmiṃ, asmiṃ, tamhi | เตสุ tesu |

**กฎ (ตำรา น.35):** ① สิ อยู่หลัง เอา ต (ที่มิใช่นปุง) เป็น **ส** · โย ทั้งสอง เป็น เอ · ต เป็น น ได้บ้าง ② ส สฺมา สฺมึ อยู่หลัง เอา ต เป็น อ ได้บ้างทุกลิงค์ ③ นํ เป็น สํ, สานํ แล้วเอา อ ข้างหน้าเป็น เอ ④ เมื่อเอา ต เป็น อ แล้ว ห้ามแปลง สฺมา เป็น มฺหา / สฺมึ เป็น มฺหิ

### 2.2 อิตถีลิงค์
| วิภัตติ | เอกวจนะ | พหุวจนะ |
|---|---|---|
| ป. | สา sā | ตา, นา tā, nā |
| ทุ. | ตํ, นํ | ตา, นา |
| ต. | ตาย tāya | ตาหิ tāhi |
| จ. | ตสฺสา, อสฺสา, ติสฺสา, ติสฺสาย tassā, assā, tissā, tissāya | ตาสํ, ตาสานํ tāsaṃ, tāsānaṃ |
| ปญ. | ตาย | ตาหิ |
| ฉ. | ตสฺสา, อสฺสา, ติสฺสา, ติสฺสาย | ตาสํ, ตาสานํ |
| ส. | ตายํ, ตสฺสํ, อสฺสํ, ติสฺสํ tāyaṃ, tassaṃ, assaṃ, tissaṃ | ตาสุ tāsu |

**กฎ:** ① อิตถีลิงค์ เอา อ การันต์เป็น อา และลบ โย ทั้ง 2 ② ส เป็น สฺสา, สฺสาย แล้วรัสสะการันต์เป็น อ หรือแปลงเป็น อิ ③ สฺมึ เป็น สฺสํ (ตำรา น.35)

### 2.3 นปุงสกลิงค์
แจกเหมือนปุงลิงค์ **แปลกแต่ ป.เอก. = ตํ · ทุ.พหุ. = ตานิ** (ตำรา น.35) → ป. ตํ | ตานิ · ทุ. ตํ | ตานิ · ที่เหลือเหมือนปุงลิงค์

## 4. อมฺห ศัพท์ (ข้า / เรา) — 2 ลิงค์แจกเหมือนกัน (ตำรา น.36)
| วิภัตติ | เอกวจนะ | พหุวจนะ |
|---|---|---|
| ป. | อหํ ahaṃ | มยํ mayaṃ (อมฺเห amhe `[มาตรฐาน]`) |
| ทุ. | มํ, มมํ maṃ, mamaṃ | อมฺเห, โน amhe, no |
| ต. | มยา, เม mayā, me | อมฺเหหิ, โน amhehi, no |
| จ. | มยฺหํ, อมฺหํ, มม, มมํ, เม mayhaṃ, amhaṃ, mama, mamaṃ, me | อมฺหากํ, อสฺมากํ, โน amhākaṃ, asmākaṃ, no (อมฺหํ `[มาตรฐาน]`) |
| ปญ. | มยา mayā | อมฺเหหิ amhehi |
| ฉ. | มยฺหํ, อมฺหํ, มม, มมํ, เม | อมฺหากํ, อสฺมากํ, โน (อมฺหํ `[มาตรฐาน]`) |
| ส. | มยิ mayi | อมฺเหสุ amhesu |
> หมายเหตุ (เทพ H5): ตำรา น.35-36 วาง ตุมฺหํ/อมฺหํ ไว้เอกวจนะ ซึ่งตรงกับไวยากรณ์มาตรฐานที่ให้รูปนี้ได้ทั้งสองวจนะ (เอก. tuyhaṃ tumhaṃ tava · พหุ. tumhākaṃ tumhaṃ vo) จึงคงเอกวจนะตามต้นฉบับและเติมพหุวจนะเป็น `[มาตรฐาน]`

**กฎสำคัญ (ตำรา น.36):** ① ตุมฺห อมฺห อยู่หน้า เอา นํ เป็น **อากํ** ② **เต โว เม โน — ต้องมีบทอื่นนำหน้าจึงใช้ได้** (enclitic — ไม่ขึ้นต้นประโยค) เช่น *อาจริโย โน* (อาจารย์ของข้า ท.) · *อยํ เต ปตฺโต* (นี้ บาตรของเจ้า)

## 7. กึ ศัพท์ (ใคร / อะไร) — การใช้ 5 แบบ (ตำรา น.40)
รูปหลัก: ปุง **โก** ko · อิต **กา** kā · นปุง **กึ** kiṃ · แจกเหมือน ย (กสฺส, เกน, กสฺมา, กสฺมึ …)

| แบบ | หน้าที่ | ตัวอย่าง |
|---|---|---|
| ปุริสสัพพนาม (ลำพัง) | ใคร, อะไร | โก คามํ อาคจฺฉติ? (อ.ใคร ย่อมมา สู่บ้าน) · กสฺส สุนโข อาวาเส รวติ? (อ.สุนัข ของใคร ย่อมร้อง ในวัด) |
| วิเสสนสัพพนาม (ประกอบนาม) | อะไร, ไหน | โก สามเณโร ปตฺเต โธวติ? (สามเณร รูปไหน) · กา ทาริกา อุยฺยานํ คจฺฉติ? (เด็กหญิง ไร) · กึ ผลํ ปิฏเก โหติ? (ผลไม้ อะไร) |
| นิบาตคำถาม | หรือ | กึ ปเนตํ อาวุโส ปฏิรูปํ? (ก็ อันนั่น สมควร หรือ) |
| นิบาตถามเหตุ | ทำไม | กึ ปาลิต ปมชฺชสิ? (อ.ท่าน ประมาทอยู่ ทำไม) |
| **กึ + จิ** (ไม่ใช่คำถาม) | ใครๆ, ไรๆ, อะไรๆ / น้อย, บาง / บางพวก (พหุ.) | โกจิ (ใครๆ) · โกจิ ชโน (ชนไรๆ) · กาจิ อิตฺถิโย (หญิงไรๆ) · กิญฺจิ ธนํ (ทรัพย์น้อยหนึ่ง) · เกจิ ชนา (ชน ท. บางพวก) · กานิจิ ภาชนานิ |

**วิธีแจก กึ+จิ:** นำ จิ ต่อท้ายรูปที่แจกแล้ว (โกจิ เกจิ กาจิ กานิจิ) · ถ้าวิภัตติลงท้ายด้วยนิคหิต **แปลงนิคหิตเป็น ญฺ**: กํ+จิ = กญฺจิ · กึ+จิ = กิญฺจิ · กสฺมึ+จิ = กสฺมิญฺจิ · **ย + กึ + จิ** = คนใดคนหนึ่ง/สิ่งใดสิ่งหนึ่ง: โยโกจิ · ยากาจิ · ยงฺกิญฺจิ

## 8. สังขยา (Saṅkhyā — การนับ) (ตำรา น.41-43)
