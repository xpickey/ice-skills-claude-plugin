# pali-language — Skill ภาษาบาลี (ไวยากรณ์ · อ่าน-แปล-แต่ง · ใช้ในงานวิจัยพุทธศาสตร์ · อ่านเอกสารบาลี)

คลังความรู้และคู่มือปฏิบัติภาษาบาลี สกัดจาก**เอกสารอบรมภาษาบาลี 5 ไฟล์ 177 หน้า** (ผศ.ดร.สุริยา รักษาเมือง ป.ธ.๙ — อิงบาลีไวยากรณ์ของสมเด็จพระมหาสมณเจ้า กรมพระยาวชิรญาณวโรรส) **ทุก claim อ้างไฟล์+เลขหน้า** เสริมช่องว่าง (สนธิ/สมาส/ตัทธิต) จาก PALIdict + ไวยากรณ์มาตรฐาน โดยติดป้ายแหล่งชัดทุกจุด · ผ่านการตรวจโดย second detector (Codex) · ภาษา: **ไทยอธิบาย · คำบาลีแสดงอักษรไทย (มีพินทุ ฺ นิคหิต ํ) คู่โรมัน IAST · ศัพท์ไวยากรณ์กำกับอังกฤษ · ตารางหลักเป็น 3 ภาษา**

## 1. กฎเหล็กของ skill (ยึดเสมอ)

1. **อ้างอิงทุก claim** — กฎ/รูปศัพท์/ตัวเลขที่ตอบ แนบ `(รหัสย่อ น.X)` ตามทะเบียน `references/10-sources.md` · เนื้อหาที่มาจากมาตรฐานสากล (ไม่ใช่เอกสารอบรม) ติดป้าย `[มาตรฐาน]`
2. **Anti-hallucination ระดับอักขระ** — รูปบาลีทุกคำต้องมาจาก paradigm ในไฟล์ 02-04 หรือพจนานุกรม ห้ามผันเดา · **พินทุ (ฺ) และนิคหิต (ํ) ต้องถูกต้อง** · โรมันต้องมี IAST diacritics ครบ (ā ī ū ṅ ñ ṭ ḍ ṇ ḷ ṃ) · ไม่แน่ใจ = บอกว่าไม่แน่ใจ + ชี้ให้ตรวจพจนานุกรม (`08` §4)
3. **แปลผิดวาจก = ผิดมาก** (ตำรา น.59) — กำหนดวาจกก่อนแปลทุกประโยค · แปลตาม**ลำดับการแปล 10** (`06` §4) · ให้**คำแปลโดยพยัญชนะก่อน**แล้วจึงแปลโดยอรรถ
4. **ความสอดคล้อง 3 อย่าง** — คุณนาม/สัพพนาม/กิริยากิตก์ ต้องมี **ลิงค์-วจนะ-วิภัตติ** ตรงนามที่ขยาย · อาขยาตต้องมี **บุรุษ-วจนะ** ตรงประธาน (`01` §4 · `06` §4.5, 4.7)
5. **พุทธพจน์ในงานวิชาการ** — ยกคำต่อคำจากฉบับมาตรฐาน + อ้าง **เล่ม/ข้อ/หน้า** + ระบุฉบับ (`08` §3) · ห้ามแปลเองแล้วเสนอเป็นคำแปลทางการ
6. **เอกสารบาลีจากไฟล์** — ห้ามใช้ OCR เป็นแหล่งเดียวของคำบาลี (พินทุ→สระอุ) และห้ามใช้ text layer เป็นแหล่งเดียวของร้อยแก้วไทย (สระอำหาย) → **dual-source** เสมอ (`09`) · ข้อความเสียห้ามซ่อมด้วยการเดา (กฎ R2 ของ ice-doc-reader)
7. **สองชั้น** (ตาม Project CLAUDE.md PART 7) — ตอบชั้น Baseline (ตามตำราอบรม) ก่อน แล้วเสนอ Advanced (สัมพันธ์ ป.ธ.3 · Warder · DPD) เป็นทางเลือก
8. โหลด**เฉพาะไฟล์ reference ที่งานต้องใช้** — อย่าโหลดทุกไฟล์พร้อมกัน (ไฟล์ 02 และ 04 ใหญ่)

## 4. งานหลักที่ skill นี้ต้องทำได้ (checklist)

### 4.1 แปลประโยคบาลีให้ผู้ใช้
① แยกบท (+สนธิ) → ② ระบุทุกบท: ศัพท์เดิม · การันต์ · ลิงค์ · วิภัตติ · วจนะ · อายตนิบาต (ตาราง) → ③ กิริยา: ธาตุ · ปัจจัย · วาจก · หมวดวิภัตติ · กาล-บท-วจนะ-บุรุษ → ④ ประกาศวาจก → ⑤ เรียงลำดับแปล 10 → ⑥ **แปลโดยพยัญชนะ** (อ./ซึ่ง/ด้วย/แก่/แต่/แห่ง/ใน ครบ) → ⑦ **แปลโดยอรรถ** → ⑧ อ้างกฎที่ใช้ `(ตำรา น.X)` · คำที่ไม่แน่ใจติด `[?]`

### 4.2 แต่งประโยคบาลีจากไทย
① วิเคราะห์ประธาน/กรรม/กิริยา/ขยาย → ② เลือกศัพท์ + ระบุการันต์-ลิงค์ + ธาตุ-หมวด (บอกที่มา) → ③ ผันนามตามหน้าที่ (ตารางอายตนิบาตย้อนกลับ) → ④ ผันคุณนาม/สัพพนามตามนาม → ⑤ ผันกิริยา (กาล → วาจก → บุรุษ-วจนะตรงประธาน) → ⑥ เรียง SOV → ⑦ **แสดงตารางวิเคราะห์ทุกบท** + ตรวจย้อน (4.1) → ⑧ เตือนว่าควรให้ผู้รู้ (ป.ธ.) ตรวจถ้าจะใช้ทางการ

### 4.3 ตรวจ/แก้คำบาลีในงานวิชาการ
เทียบ: รูปไทยแบบคัมภีร์ (พินทุ/นิคหิต) vs รูปสามัญ ใช้ถูกบริบท (`08` §2) · IAST diacritics ครบ (รัน `pali_check.sh` P3-P4) · รูปโรมันได้จาก `pali_translit.py` แล้วยืนยันกับพจนานุกรม · คำบาลีใช้ IAST คำไทยใช้เกณฑ์ราชบัณฑิตยสภา ห้ามปน (`11` §4) · ชื่อหลักธรรมสะกดตรงพจนานุกรมพุทธศาสน์ · การอ้างพระไตรปิฎกครบ เล่ม/ข้อ/หน้า + ฉบับ (`08` §3) · พุทธพจน์ยกคำต่อคำ · แยกชั้นคัมภีร์ถูก

### 4.4 ถอดอักษรไทย↔โรมันและอ่านบาลีโรมัน
① ระบุระบบของต้นทาง (IAST / ISO ṁ / PTS ŋ / Velthuis ASCII — `11` §1) → ② รูปไทยต้องเป็นอักขรวิธีบาลี (พินทุ/นิคหิต) ไม่ใช่คำไทย → ③ รัน `pali_translit.py` ตามทิศทาง (`11` §3.4) และอ่านคำเตือนทาง stderr ทุกข้อ → ④ ยืนยันรูปกับ DPD/PED (`11` §5) → ⑤ ในงานวิชาการเขียน IAST ครบ diacritics และสม่ำเสมอทั้งเล่ม (`11` §4 · `08` §2) → ⑥ อ่านออกเสียงตาม `11` §2 · สอน/ฝึก → บทเรียน `11` §8
