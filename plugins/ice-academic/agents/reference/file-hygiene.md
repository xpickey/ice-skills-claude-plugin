> **ใช้กับ:** ทุก agent + L0 session · ไฟล์ทำงานทุกชนิด — render PDF/PNG, ภาพ crop ตรวจงาน,
> ไฟล์ทดสอบ, build script รายโปรเจกต์, spec, ไฟล์ระหว่างทางทุกอย่างที่ไม่ใช่ deliverable

## กฎ 6 ข้อ

**① ค่าเริ่มต้น = ใต้โฟลเดอร์งานของ artifact เสมอ**
- ไฟล์สร้างงาน (spec / build script / ไฟล์ระหว่างทาง) → `<โฟลเดอร์งาน>/_build/`
- หลักฐานตรวจของอริส (render, crop, PDF เทียบ) → `<โฟลเดอร์งาน>/_build/_qa/`
- `<โฟลเดอร์งาน>` = โฟลเดอร์ที่ artifact ตัวจริงอยู่ หรือโฟลเดอร์ที่ user สั่งให้ save

**② งานที่ไม่ผูกโปรเจกต์** → session scratchpad ที่ระบบให้มา (`/private/tmp/claude-…/scratchpad`)

**③ ทางเบี่ยงของ PowerPoint AppleScript (ที่มาของขยะรอบนี้):** PowerPoint sandbox เขียน
`/private/tmp` ไม่ได้ → ใช้ staging `~/Documents/.ice-staging/` (โฟลเดอร์ซ่อนเดียว ชื่อตายตัว)
แล้ว**ย้ายเข้า `_build/_qa/` ทันทีในคำสั่งเดียวกัน** + ลบ staging ให้ว่าง — ห้ามทิ้งค้าง

**④ 🔴 ห้ามสร้างไฟล์/โฟลเดอร์ใหม่ตรง ๆ ใต้ `~/Documents` หรือ `~/Documents/Claude` (root) เด็ดขาด**
เคสจริง 2026.08.05: `~/Documents/_qa_aris_vfin/` (11 MB) + `_aris_qa_r2_*.pdf` + `qa_s6_*.pptx`
กระจายใต้ ~/Documents — user เป็นคนเจอ ไม่ใช่ระบบ

**⑤ ไม่แน่ใจว่าเก็บที่ไหน = ถาม user** — การถามถูกกว่าการเดาผิดเสมอ

**⑥ จบงานต้องเก็บกวาด** — หลักฐาน QA ที่อ้างใน QA-log เก็บถาวรใน `_build/_qa/` ได้ ·
ไฟล์ระหว่างทางอื่นลบทิ้ง · ก่อนจบ DELIVERY REPORT ให้ `ls` ยืนยันว่าไม่มีไฟล์หลงนอกโฟลเดอร์งาน
